# Обзор на телефоне и доступность релизов Archive

Проверка по скриншоту пользователя, 15 октября 2026 года.

## Что воспроизведено на реальных данных

- `Zemfira-Myaso-SINGLE-WEB-RU-2022-2o22`: в [metadata](https://archive.org/metadata/Zemfira-Myaso-SINGLE-WEB-RU-2022-2o22) находится RAR (около 10 МБ), а не отдельный MP3. FLAC-вариант этого релиза тоже упакован в RAR. Прямое воспроизведение таких контейнеров не поддерживается; автоматическая распаковка в этом исправлении не добавлена.
- [Zemfira](https://archive.org/metadata/Zemfira): настоящий концертный релиз с десятью MP3-дорожками. `creator` отсутствует, исполнитель записан в `artist`. Название совпадает с именем исполнителя, а subject не содержит его имени. Поэтому прежний фильтр исключал альбом.
- В этом же релизе ZIP-сборник имеет формат `VBR MP3`, а поле `original` — массив. Нельзя определять воспроизводимость только по строке `format`; такие ZIP попадали в очередь как песни.
- Названия MP3 в этом релизе дважды испорчены перекодировкой UTF-8. Прежний жадный выбор CP1251 останавливался на нечитаемой кириллице.
- По «Океан Эльзы» новые варианты написания дают три аудиорелиза в текущем Archive: `Ne tvoja vijna`, `Obnimi (Callmearco Remix) (Bass Boosted)`, `Дякую Тобі Мінус`. Это **не три оригинальных студийных песни** и не полная дискография. Большинство остальных совпадений общего поиска — эфиры, разговорные записи, видео и упоминания.

## Исправления

- Цельные алиасы Земфира/Zemfira и Океан Ельзи/Эльзы/Эльзи/Elzy/Elzi, украинские буквы в транслитерации. Варианты написания отправляются одним OR-запросом в каждой фазе, чтобы пагинация не пересортировывала отдельные алфавиты задним числом.
- Заголовки релизов больше не перестают проверяться после восьми совпадений по creator. Сильные совпадения остаются первыми; защита неоднозначных коротких имён сохранена.
- Самоназванные релизы без creator подтверждаются по metadata.artist и аудиофайлам; произвольные совпадения названия не принимаются автоматически.
- Проверка subject-кандидатов выполняется до заполнения страницы, максимум четыре metadata-запроса одновременно. Отклонённые записи не заслоняют последующие подходящие результаты.
- Лимит сканирования свободного поиска помечается как частичная выдача, без бесконечной пустой следующей страницы.
- ZIP/RAR, плейлисты и служебные ресурсы никогда не выдаются за MP3 даже при неверной метке формата. Закрытые файлы отбрасываются. Ссылки `original` и номера дорожек помогают выбрать одно кодирование; 64 kbit/s не вытесняет нормальный MP3.
- При двойной кодировке сначала пробуем валидные улучшающие шаги UTF-8; сохранён CP1251 fallback. Файлы с именами из одних номеров не исчезают из списка.
- Отдельные состояния для RAR/ZIP, ограниченного доступа, неподдерживаемого аудио и отсутствующих файлов. Сетевая ошибка не равна «нет аудио»; есть повтор загрузки. Запрос metadata ограничен 15 секундами.
- На телефоне раздел находится рядом с заголовком «Обзор», поле запроса — первым, параметры компактнее. Счётчик релизов рядом с запросом, объяснение ограничений каталога — после результатов. В альбоме компактная обложка слева, действия и дорожки выше, без большой пустой шапки.

## Проверка

- Добавлено 11 регрессионных тестов: контейнеры, двойная кодировка, настоящий self-title case, алиасы, порог восьми записей, отфильтрованные страницы, лимит выдачи, состояния RAR/ошибки, все восемь интерфейсов при 320/390 px и масштабе 125%.
- Production-сборка: через UI переключены все восемь интерфейсов; реальные запросы Archive, RAR-карточка и десять дорожек с читаемыми названиями проверены во всех восьми. Дополнительно просмотрены 320 и 1440 px. Ошибок JavaScript нет.
- Production-проверка релиза проверяет состав и интерфейс, а не лицензии и не декодирование каждой реальной песни. Chromium; физические устройства и Safari отдельно не проверялись.

Финальная валидация:
- `npm run typecheck` и `npm run build` прошли.
- Полный запуск 165 тестов с двумя workers: 162 прошли сразу. Два теста столкнулись с таймаутами; ещё один проверял старую полноширинную геометрию селектора.
- Проверка геометрии обновлена под новую строку заголовка: минимальная ширина 160 px, touch-height 44 px, отсутствие пересечений и выходов за экран, одинаковый вертикальный центр.
- CDDA-тест ждёт выполнения route-handler, а не только события request, которое может прийти раньше записи диапазона.
- Все три проверки повторно прошли последовательно (3/3). Таким образом, на текущем коде пройдены все 165 сценариев; это не заявление об одном полностью зелёном параллельном запуске.
