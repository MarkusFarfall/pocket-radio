# Статистика: что считается и как устроено

Страница «Статистика» — личный отчёт по локальным записям устройства. Ничего не отправляется в сеть:
сессии и события читаются из IndexedDB (`sessions`, `events`) через `useSessions()` / `useEvents()`.

## Блоки страницы

| Блок | Что показывает | Откуда данные |
| --- | --- | --- |
| Портрет слушателя | Прозвище («Ночной радист», «Вечерний меломан»…), пояснение и три признака | доли частей суток + жанры + офлайн + концентрация на станции |
| Звуковой отпечаток | 24 луча по часам, в центре — главная часть суток | `secondsByHour` |
| Метрики | Активные дни, сессии, средняя сессия, офлайн, трафик | сессии + битрейт станции |
| Карта года | 53 недели × 7 дней, четыре уровня интенсивности, подсказка по дню | `buildHeatmap` |
| Динамика по дням | Линия периода, пунктир прошлого периода, средняя | `secondsByLocalDay` |
| Что звучало | Донат по жанрам / настроению / типу / городу | снимки сессий |
| Ритм недели | Матрица 7 × 24: когда включаете эфир | `weeklyMatrix` |
| Любимые станции | Топ-6 по времени прослушивания | агрегат сессий |
| Рекорды | Лучший день, самая длинная сессия, любимый день, пиковый час, серия | `buildRecords` |
| Достижения | 13 бейджей с прогрессом | `buildAchievements` |
| В понятном | Песни по 3:30, «Abbey Road», аудиокниги, дни в звуке | `buildComparisons` |
| Стабильность | Ошибки, буферизация, доля ожидания | события `error` / `buffer` |
| Последние сессии | Лента с группировкой по дням | активные сессии |

Все производные функции живут в `src/lib/statsInsights.ts` и покрыты `tests/stats-insights.spec.ts`.

## Периоды

7 / 30 дней, год и «всё время». Границы считаются по локальным календарным дням (`addCalendarDays`),
поэтому переход на летнее время не ломает суммы. Для «всего времени» прошлого периода нет — сравнение
не показывается.

## Честные ограничения

- В сессии хранится суммарное `seconds`, а не покадровая история: при пересечении полуночи время делится
  пропорционально длительности сессии (`secondsInRange`).
- Паузы внутри сессии неизвестны, поэтому «средняя сессия» — оценка.
- Трафик = секунды × битрейт / 8, а не показания сетевого счётчика.
- Карта года на узких экранах показывает последние полгода (колонки скрываются через CSS, данные не теряются).
- Если жанр или настроение не сохранились в сессии, время попадает в подпись «данные не сохранены», а не
  в «Другие».

## Визуальный слой

`src/stats.css` использует только токены (`--surface`, `--line`, `--accent`, `--muted`), поэтому блоки
автоматически подстраиваются под светлую и тёмную тему и под все восемь интерфейсов. Проверено
скриншотами на 320 / 390 / 1280 px и во всех стилях: горизонтального скролла нет.

## Тесты

- `tests/stats.spec.ts` — сводные числа (время, офлайн, трафик) и новый блок аналитики на реальных данных.
- `tests/stats-insights.spec.ts` — чистые функции: часы, дни недели, матрица, уровни карты, персона, доли.
- `tests/premium-designs.spec.ts` — страница не ломает вёрстку ни на одной ширине и ни в одном стиле.
