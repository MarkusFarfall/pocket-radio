# Четыре дополнительных спокойных интерфейса

**Настройки → Оформление → Стиль → Спокойные пространства.**

Новые варианты дополняют, а не заменяют Классику, Редакцию, Медиатеку и Пульт. Всего доступно восемь интерфейсов.

| Интерфейс | Оболочка | Главная и коллекция | Начальные настройки |
| --- | --- | --- | --- |
| Панорама | Единая верхняя строка навигации на компьютере; прокручиваемые главы на телефоне | Широкий первый экран, светлые поверхности, полки обложек, воздушная сетка каталога | Фарфор, тёмно-зелёный акцент, воздушный плеер с обложкой и зоной управления |
| Фокус | Небольшой плавающий остров навигации; центрированная рабочая область | Компактная карточка первого включения, поиск и избранное на главной, каталог списком по умолчанию, плейлисты строками | Фарфор, нейтральный акцент, компактный центрированный плеер |
| Ателье | Слева разделы и реальные плейлисты пользователя; на телефоне меню снизу | Альбомный разворот, стопка обложек своих плейлистов, коллекции и близкие частоты в двух колонках | Лён, тёплый нейтральный акцент, плеер-альбом без виниловой деки |
| Ноктюрн | Нижняя навигация на телефоне и компьютере, плеер над ней | Тёмный кинематографичный первый экран, большие панорамные карточки, крупные плейлисты | Тёмный графит, светлый нейтральный акцент, спокойная сцена с нижним островом управления |

Новые палитры доступны отдельно в настройках цвета; интерфейсы не привязаны навечно к начальным палитрам. Плеер автоматически следует выбранному интерфейсу во всех размерах; отдельные старые скины больше не подмешиваются. См. [Единый плеер](app-player.md).

## Данные и переключение

- Используется прежний механизм `appDesign`: копия оформления Классики создаётся только при первом уходе из неё, не перезаписывается переходами между новыми вариантами и восстанавливается при возврате.
- Масштаб и ограничение анимаций сохраняются. Все четыре варианта проверяются также на телефоне шириной 320 px с масштабом 125%.
- Каталог хранит режим отдельно для каждого из восьми интерфейсов. Только Пульт и Фокус начинают со списка.
- Единый portal страниц, аудиодвижок, очередь, EQ, модальные окна и пользовательские данные не дублируются.
- Поиск и фильтр избранного Фокуса работают по реальным станциям. Они не фильтруют незаметно главные других интерфейсов.
- Боковая фонотека Ателье открывает выбранный реальный плейлист, а не демонстрационный экран.

## Файлы

- `src/components/PremiumLayout.tsx` — четыре структуры оболочки с общими рабочими слотами.
- `src/views/PremiumHome.tsx` — четыре композиции главной на станциях и плейлистах пользователя.
- `src/components/PremiumPreviewHome.tsx` — явно схематические, неинтерактивные миниатюры главных.
- `src/premium-designs.css` — оболочки, страницы, адаптивность и изоляция миниатюр.
- `public/designs/panorama.jpg`, `nocturne.jpg` — локальные AI-сгенерированные декоративные фоны. Это не обложки станций или альбомов. При недоступном изображении остаётся читаемый цветовой фон; внешнего CDN не требуется.
- `src/lib/themes.ts` — три независимые нейтральные палитры.

`AppLayout` выбирает старую или новую оболочку. Миниатюры и настоящее приложение используют один структурный renderer. Селекторы слотов с `data-layout` предотвращают влияние внешнего выбранного интерфейса на вложенные миниатюры.

## Автоматические проверки

`tests/premium-designs.spec.ts` добавляет девять сценариев:
- все разделы и выбор интерфейса на 320 / 768 / 1024 / 1440 px;
- четыре разные сетки оболочек и неизменность миниатюр во всех восьми внешних интерфейсах;
- клавиатурное переключение всех восьми вариантов, сохранение DOM-host, поиска, настроек, очереди и воспроизведения;
- открытый полный плеер при переходах между новыми интерфейсами;
- пустые состояния и масштаб 125% на телефоне;
- поиск Фокуса, избранное, реальные ссылки фонотеки Ателье и страницы плейлиста;
- сохранение индивидуального режима каталога после перезагрузки и доступность локальных декоративных изображений.

Существующие тесты интерфейсов обновлены для восьми карточек выбора. Команды проверки: `npm run typecheck`, `npm run build`, `npm test`.

Браузер автоматизации — Chromium. Физические устройства iOS/Android и Safari отдельно не проверялись.
